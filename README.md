# Управление кадрами

Учебное настольное приложение на C# для кадрового учёта. Решение открывается в Visual Studio и включает:

- `HrManagement.App` — WPF-приложение на .NET 8 с MVVM и Entity Framework Core;
- `HrManagement.Core` — проверяемая бизнес-логика;
- `HrManagement.Tests` — xUnit-тесты правил кадрового учёта;
- Microsoft SQL Server — база данных `HrManagement`.

## Запуск

1. Скопировать `Database/001_create_database.example.sql` в `Database/001_create_database.sql`, задать собственный пароль вместо `REPLACE_WITH_DATABASE_PASSWORD`. Запустить SQL Server и выполнить скрипт с административными правами.
2. В базе `HrManagement` выполнить `Database/002_full_hr_schema.sql`.
3. Скопировать `src/HrManagement.App/appsettings.example.json` в `appsettings.json` в той же папке. Указать адрес сервера и заданный пароль. Локальные файлы с паролями исключены из Git.
4. Открыть `HrManagement.sln` в Visual Studio.
5. Назначить `HrManagement.App` запускаемым проектом и нажать `F5`.

Учебный вход: `hr`, пароль `Hr2026!`.

## Модель данных

Полная SQL-схема содержит 15 таблиц, 108 полей и 21 внешний ключ. Скрипт `002_full_hr_schema.sql` можно повторно применять к первоначальной базе из шести таблиц: существующие записи не удаляются, новые поля в них допускают NULL. Перед обновлением рабочей базы нужно сделать резервную копию.

В `docs/Model` находятся общая диаграмма Мартина и три крупных фрагмента в SVG, исходники DOT и машинный словарь `hr_model.json`. Подробный словарь приведён в ЛР3.

Клиент WPF пока использует шесть EF Core-сущностей: подразделения, должности, сотрудники, отсутствия, пользователи и аудит. Таблицы штатных единиц, договоров, приказов, отпусков и их видов, документов, образования, ролей и назначений ролей развёрнуты в SQL Server, но отдельных форм для них нет. Авторизация клиента использует поле `UserAccounts.Role`; многоролевая модель `Roles` / `UserRoles` подготовлена на уровне БД.

После расширения проверены 15 таблиц, 108 полей, 21 внешний ключ, отсутствие отключённых и недоверенных FK, повторное применение SQL-скрипта и сохранность исходных записей. Повторный запуск WPF-клиента после этого обновления не выполнялся. C#-код и бинарные файлы не менялись.

## Тестирование

Полный план из 28 тестовых примеров и расчёт покрытия требований: [docs/testing/test-plan.md](docs/testing/test-plan.md).

Модульные тесты находятся в `tests/HrManagement.Tests`. Запуск: `dotnet test tests/HrManagement.Tests/HrManagement.Tests.csproj`.

Учётные записи и данные, создаваемые `DatabaseInitializer`, предназначены только для учебной демонстрации.
